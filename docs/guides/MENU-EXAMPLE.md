# Menu Example — WHISKAY v0.10.12

Menu ringkas untuk build eksperimental private/self. Daftar command aktual berasal dari plugin registry; contoh ini bukan konfigurasi akses tambahan.

```text
━━ WHISKAY PRIVATE RUNTIME ━━

CORE
.menu — menu command
.mode status — status mode self/public
.mode self — owner-only mode
.mode groups on|off — akses owner di grup saat self

INSTAGRAM ACCOUNT (SINGLE SESSION)
.igcheck — diagnosis adapter/session
.iglogin — login pertama secara eksplisit
.igprofile — profil dari session aktif
.igsync — simpan snapshot statistik
.igstats — statistik tersimpan

ORGANIC GROWTH
.igpanel — dashboard pertumbuhan
.igservices — playbook strategi organik
.igservice <strategy-id> — detail strategi
.igcampaign create <nama campaign> — buat campaign pada akun session aktif
.igcampaign list — daftar campaign akun aktif
.igcampaign progress <ID> — progres campaign
.igcampaign goal <ID> <followers> <YYYY-MM-DD> — target pengukuran
.igfunnel <ID> — analisis funnel

CONTENT INTELLIGENCE
.igcontent add — catat Insights konten
.igcontent list — daftar konten
.igcontent report <ID> — laporan konten
.igcontent compare — bandingkan konten

REFERRAL (OPTIONAL VERIFIED BACKEND)
.referralstatus — status claim queue
.referralprocess [1-25] — proses claim terverifikasi
```

Tidak tersedia command saldo, balance, wallet, kredit, ledger, order berbayar, atau pembayaran. Tidak ada auto-follow atau artificial follower delivery.
